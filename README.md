# tvttvvv 복셀 크래프트

**바로 플레이: https://tvttvvv.github.io/vibecoding/**

tvttvvv가 만든 복셀 크래프트는 설치 없이 브라우저에서 바로 하는 무료 블록 샌드박스 게임입니다.
태블릿, 휴대폰, PC 어디서나 할 수 있어요.

- 무한 지형: 강과 바다, 숲과 사막, 동굴과 광석, 마을
- 서바이벌과 크리에이티브, 친구와 함께하는 멀티플레이
- 제작, 화로, 농사, 동물 번식, 활, 마법 부여, 양조와 물약
- 레드스톤: 레버, 버튼, 압력판, 램프, 중계기, 비교기, 피스톤, 관측기, TNT
- 지하 구조물: 던전(몬스터 생성기), 폐광, 자수정 정동, 협곡
- 네더(요새, 블레이즈, 피글린)와 엔드(엔더 드래곤)

터치(조이스틱)와 키보드·마우스 모두 지원합니다. 세계와 인벤토리는 기기에 저장됩니다.
